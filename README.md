# The Weakest Link
This is version of the Weakest Link, a general knowledge quiz game where questions are asked and points can be earned (in a compounded manner) by building a chain of correct answers.

## Link To Game
[https://nathan-d-george.github.io/the-weakest-link-react/](https://nathan-d-george.github.io/the-weakest-link-react/)

## Inputs
- Players names
- XLSX/CSV with format of `Question` - `Answer`
- Desired round length
- Settings for question order and answer display.
